# شرح: أنواع البيانات والتحويل

## الأنواع الأساسية في بايثون

| النوع | الاسم | مثال | الوصف |
|-------|------|------|-------|
| `int` | عدد صحيح | `10`, `-3`, `0` | أعداد بلا كسور |
| `float` | عدد عشري | `3.14`, `-0.5` | أعداد بفاصلة عشرية |
| `str` | نص | `"hello"` | سلسلة محارف |
| `bool` | منطقي | `True`, `False` | صح أو خطأ |
| `complex` | عدد مركّب | `2 + 3j` | أعداد بجزء تخيّلي |

## دالة type()

تُستخدم لمعرفة نوع أي قيمة أو متغيّر:

```python
print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hi"))     # <class 'str'>
print(type(True))     # <class 'bool'>
```

## النوع المنطقي bool

- له قيمتان فقط: `True` و `False` (بحرف كبير في البداية).
- داخلياً: `True` تساوي `1` و `False` تساوي `0`.

```python
print(True + True)   # 2
```

## التحويل بين الأنواع (Type Casting)

نستخدم دوال التحويل لتغيير نوع القيمة:

| الدالة | التحويل إلى |
|--------|-------------|
| `int(x)` | عدد صحيح |
| `float(x)` | عدد عشري |
| `str(x)` | نص |
| `bool(x)` | منطقي |

### أمثلة

```python
int("25")      # 25   (نص إلى عدد صحيح)
float("3.5")   # 3.5  (نص إلى عشري)
str(100)       # "100" (عدد إلى نص)
int(3.9)       # 3    (يقتطع الكسر ولا يقرّب!)
```

### ⚠️ ملاحظات مهمة

- `int(3.9)` تُعطي `3` لأنها **تقتطع** الجزء العشري ولا تقرّب.
- `int("abc")` يسبب **خطأً (ValueError)** لأن النص ليس رقماً.
- `int("3.5")` يسبب خطأً أيضاً؛ يجب المرور بـ `float` أولاً: `int(float("3.5"))`.

## القيم الفارغة والصفرية مع bool

القيم التالية تعتبر `False` عند تحويلها إلى منطقي:

```python
bool(0)     # False
bool("")    # False
bool([])    # False
bool(5)     # True
bool("hi")  # True
```

## نقاط مهمة للحفظ

- `type()` تكشف نوع القيمة.
- `int()` **تقتطع** الكسر ولا تقرّبه.
- تحويل نص غير رقمي إلى `int` يسبب **ValueError**.
- `True = 1` و `False = 0` داخلياً.
