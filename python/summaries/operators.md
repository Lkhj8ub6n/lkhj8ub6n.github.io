# شرح: العمليات والمعاملات

## المعاملات الحسابية (Arithmetic Operators)

| المعامل | العملية | مثال | الناتج |
|---------|---------|------|--------|
| `+` | جمع | `5 + 2` | `7` |
| `-` | طرح | `5 - 2` | `3` |
| `*` | ضرب | `5 * 2` | `10` |
| `/` | قسمة (عشرية) | `5 / 2` | `2.5` |
| `//` | قسمة صحيحة | `5 // 2` | `2` |
| `%` | باقي القسمة | `5 % 2` | `1` |
| `**` | الأس (القوة) | `5 ** 2` | `25` |

### فروق مهمة

- **`/`** تُعطي دائماً نتيجة **float** حتى لو كانت القسمة تامة: `4 / 2` = `2.0`.
- **`//`** القسمة الصحيحة تُهمل الكسر (تقرّب للأسفل): `7 // 2` = `3`.
- **`%`** باقي القسمة مفيد لمعرفة الأعداد الزوجية/الفردية: `n % 2 == 0` يعني زوجي.

## أولوية العمليات (Precedence)

الترتيب من الأعلى للأدنى:

1. الأقواس `()`
2. الأس `**`
3. الضرب والقسمة `*  /  //  %`
4. الجمع والطرح `+  -`

```python
print(2 + 3 * 4)      # 14  (الضرب أولاً)
print((2 + 3) * 4)    # 20  (القوس أولاً)
print(2 ** 3 ** 2)    # 512 (الأس من اليمين لليسار)
```

## معاملات الإسناد المختصرة

| المعامل | المعنى |
|---------|--------|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 3` | `x = x * 3` |
| `x /= 3` | `x = x / 3` |
| `x //= 3` | `x = x // 3` |
| `x %= 3` | `x = x % 3` |

## عمليات النصوص (Strings)

النصوص تدعم بعض المعاملات:

### الدمج (+)

```python
"Hello" + " " + "World"   # "Hello World"
```

### التكرار (*)

```python
"ab" * 3    # "ababab"
"-" * 10    # "----------"
```

### ⚠️ لا يمكن جمع نص مع رقم

```python
"العمر: " + 20      # خطأ! TypeError
"العمر: " + str(20) # صحيح → "العمر: 20"
```

## المعاملات المنطقية والمقارنة

| المعامل | المعنى |
|---------|--------|
| `==` | يساوي |
| `!=` | لا يساوي |
| `>` `<` | أكبر / أصغر |
| `>=` `<=` | أكبر أو يساوي / أصغر أو يساوي |
| `and` | و (كلاهما صحيح) |
| `or` | أو (أحدهما صحيح) |
| `not` | نفي |

نتيجة المقارنة دائماً قيمة منطقية `True` أو `False`:

```python
print(10 > 3)        # True
print(5 == "5")      # False (رقم لا يساوي نص)
print(3 < 5 and 5 < 10)  # True
```

## نقاط مهمة للحفظ

- `/` تُرجع **float** دائماً، و`//` تُرجع قسمة صحيحة.
- `%` يُستخدم لإيجاد الباقي وكشف الزوجي/الفردي.
- `**` هو معامل الأس.
- لا يمكن دمج نص مع رقم مباشرةً؛ استخدم `str()`.
