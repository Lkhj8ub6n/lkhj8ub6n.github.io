# شرح: أول برنامج — الطباعة والتعليقات

## دالة الطباعة print()

`print()` هي الدالة المستخدمة لعرض المخرجات على الشاشة. أشهر أول برنامج:

```python
print("Hello, World!")
```

المخرج:

```
Hello, World!
```

### طباعة عدة قيم

يمكن طباعة أكثر من قيمة بفصلها بفاصلة `,` وتُطبَع بينها مسافة تلقائياً:

```python
print("العمر:", 20)
```

المخرج: `العمر: 20`

### المعامل sep (الفاصل)

يحدد ما يوضع **بين** القيم (الافتراضي مسافة واحدة):

```python
print("2025", "08", "14", sep="-")
```

المخرج: `2025-08-14`

### المعامل end (النهاية)

يحدد ما يوضع **في نهاية** الطباعة (الافتراضي سطر جديد `\n`):

```python
print("مرحبا", end=" ")
print("بالعالم")
```

المخرج: `مرحبا بالعالم` (في سطر واحد)

## النصوص (Strings)

النص يُكتب بين علامتي اقتباس:

- علامة مفردة: `'مرحبا'`
- علامة مزدوجة: `"مرحبا"`
- كلاهما صحيح، لكن يجب أن تتطابق البداية مع النهاية.

## المحارف الخاصة (Escape Characters)

| المحرف | المعنى |
|--------|--------|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (Tab) |
| `\\` | شرطة خلفية `\` |
| `\"` | علامة اقتباس مزدوجة داخل النص |

مثال:

```python
print("السطر الأول\nالسطر الثاني")
```

## التعليقات (Comments)

التعليقات نصوص يتجاهلها المفسّر، تُستخدم للشرح وتوضيح الكود.

### التعليق السطري

يبدأ بالرمز `#` ويمتد حتى نهاية السطر:

```python
# هذا تعليق سطري
print("Hi")   # تعليق بعد أمر
```

### التعليق متعدد الأسطر

يُكتب عادةً بين ثلاث علامات اقتباس:

```python
"""
هذا تعليق
يمتد على عدة أسطر
"""
```

## نقاط مهمة للحفظ

- `print()` تُنهي كل طباعة بسطر جديد افتراضياً بسبب `end="\n"`.
- `sep` يفصل بين القيم، و`end` يحدد نهاية السطر.
- التعليق السطري يبدأ بـ **`#`**.
- المفسّر **يتجاهل** التعليقات تماماً عند التنفيذ.
