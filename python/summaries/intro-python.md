# شرح: التعريف بلغة بايثون

## ما هي لغة بايثون؟

**بايثون (Python)** هي لغة برمجة عالية المستوى، سهلة القراءة والكتابة، تُستخدم في:

- تطوير الويب (Django, Flask)
- الذكاء الاصطناعي وتعلّم الآلة
- تحليل البيانات
- الأتمتة وكتابة السكربتات
- تطوير الألعاب والتطبيقات

أنشأها **جيدو فان روسم (Guido van Rossum)** عام **1991**، وسُمّيت على اسم فرقة الكوميديا البريطانية *Monty Python* وليس الثعبان.

## لماذا بايثون؟

| الميزة | الشرح |
|--------|-------|
| **سهلة** | صياغة (Syntax) قريبة من اللغة الإنجليزية |
| **مفسّرة (Interpreted)** | تُنفّذ سطراً بسطر دون الحاجة لترجمة كاملة مسبقاً |
| **متعددة الاستخدامات** | تصلح لأغلب المجالات البرمجية |
| **مجتمع ضخم** | مكتبات جاهزة كثيرة ودعم واسع |
| **مفتوحة المصدر** | مجانية بالكامل |

## بايثون لغة مفسّرة

بايثون لغة **مفسّرة (Interpreted)** وليست **مترجمة (Compiled)**:

- **المفسّر (Interpreter)** يقرأ الكود وينفّذه سطراً بسطر.
- لا تحتاج خطوة ترجمة منفصلة كما في C أو Java.
- هذا يجعل التطوير أسرع، لكن التنفيذ قد يكون أبطأ قليلاً.

## تثبيت وتشغيل بايثون

1. حمّل بايثون من الموقع الرسمي **python.org**.
2. تأكد من التثبيت عبر الأمر:

```bash
python --version
```

3. طرق تشغيل الكود:
   - **الوضع التفاعلي (Interactive / REPL):** تكتب الأوامر وتُنفَّذ مباشرة.
   - **ملف سكربت:** تحفظ الكود في ملف بامتداد **.py** ثم تشغّله:

```bash
python my_program.py
```

## أشهر بيئات الكتابة (IDE / Editors)

- **IDLE** — يأتي مع بايثون افتراضياً.
- **VS Code** — محرر خفيف وقوي.
- **PyCharm** — بيئة متكاملة مخصّصة لبايثون.
- **Jupyter Notebook** — ممتاز لتحليل البيانات.

## نقاط مهمة للحفظ

- امتداد ملف بايثون هو **`.py`**.
- بايثون **حسّاسة لحالة الأحرف (Case-Sensitive)**: `Name` تختلف عن `name`.
- المسافة البادئة (**Indentation**) جزء أساسي من بناء الكود، وليست مجرد تنسيق.
