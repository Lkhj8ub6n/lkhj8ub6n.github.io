# شرح: المتغيرات والإدخال

## ما هو المتغيّر (Variable)؟

المتغيّر هو **اسم يشير إلى قيمة** مخزّنة في الذاكرة. في بايثون ننشئ متغيراً بمجرد إسناد قيمة إليه:

```python
name = "Yazeid"
age = 20
pi = 3.14
```

- علامة `=` هي **معامل الإسناد (Assignment)**، وليست المساواة الرياضية.
- لا حاجة للإعلان عن النوع مسبقاً؛ بايثون تستنتجه تلقائياً (**Dynamic Typing**).

## قواعد تسمية المتغيرات

**مسموح:**
- يبدأ بحرف أو شرطة سفلية `_`.
- يحتوي على حروف وأرقام وشرطات سفلية.

**ممنوع:**
- أن يبدأ برقم: `2name` ❌
- استخدام مسافة أو رموز خاصة: `my name`, `my-name` ❌
- استخدام الكلمات المحجوزة (Keywords) مثل: `if`, `for`, `class`, `print`... كأسماء.

**تذكّر:** الأسماء **حسّاسة لحالة الأحرف**، فـ `Age` تختلف عن `age`.

## إعادة الإسناد وتبديل الأنواع

يمكن تغيير قيمة المتغيّر ونوعه في أي وقت:

```python
x = 10        # عدد صحيح
x = "hello"   # صار نصاً
```

## الإسناد المتعدد

```python
a, b, c = 1, 2, 3
x = y = z = 0
```

## قراءة المدخلات input()

الدالة `input()` تقرأ نصاً يكتبه المستخدم من لوحة المفاتيح:

```python
name = input("اكتب اسمك: ")
print("مرحباً", name)
```

### ⚠️ نقطة مهمة جداً

`input()` تُعيد القيمة **دائماً كنص (str)** حتى لو أدخل المستخدم رقماً.

لذلك لإجراء عمليات حسابية يجب **تحويل** النص إلى رقم:

```python
age = int(input("كم عمرك؟ "))
print("بعد سنة سيكون عمرك", age + 1)
```

لو لم نستخدم `int()` فإن `age + 1` سيسبب خطأً لأننا نجمع نصاً مع رقم.

## نقاط مهمة للحفظ

- إنشاء المتغيّر يتم عبر **الإسناد** `=`.
- بايثون **ديناميكية الأنواع**: النوع يُستنتج من القيمة.
- `input()` تُرجع **str دائماً**.
- استخدم `int()` أو `float()` لتحويل مدخلات الأرقام.
