# الرتب ومصادر التجنيد

### أ. الضباط
**مصادر التجنيد:**
1. خريجو: **جامعة مؤتة/الجناح العسكري** • **كلية الملك الحسين الجوية** • **كلية الأمير حسن للعلوم الإسلامية**.
2. **فرسان المستقبل**. 3. **الضباط الجامعيون المهنيون**. 4. **ترفيع الرتب الأخرى** إلى رتبة ضابط.

> تُرتدى الرتب مع كلمة **(الجيش العربي)** على الكتفين لكافة الرتب.

| الرتبة | الشارة |
|---|---|
| ملازم | نجمة سباعية |
| ملازم أول | نجمتان سباعيتان |
| نقيب | ثلاث نجوم سباعية |
| رائد | التاج الهاشمي |
| مقدم | نجمة سباعية يعلوها التاج الهاشمي |
| عقيد | نجمتان سباعيتان يعلوهما التاج الهاشمي + ياقتان حمراوان على القبة |
| عميد | ثلاث نجوم سباعية يعلوها التاج الهاشمي + ياقتان حمراوان |
| لواء | سيفان متقاطعان + نجمة سباعية + ياقتان حمراوان |
| فريق | سيفان متقاطعان + تاج + ياقتان حمراوان |
| فريق أول | سيفان متقاطعان + نجمة + تاج + ياقتان حمراوان |
| **مشير** | سنبلتان مكللتان بالغار + سيفان يعلوهما التاج + ياقتان حمراوان |

📌 يرتدي **جلالة الملك** القائد الأعلى رتبة **مشير بدون إشارة الجيش العربي**، لأنه القائد العام لجميع الوحدات العسكرية والأمن العام وكافة الوحدات الأخرى.

### ب. الرتب الأخرى (الأفراد)
**مصادر التجنيد:** المتطوعون (عن طريق **مديرية شؤون الأفراد**) • المكلفون (عند إقرار **الخدمة الإلزامية**).

| الرتبة | الشارة |
|---|---|
| جندي مكلف | — |
| جندي أول | شريطة واحدة على الذراع |
| عريف | شريطتان على الذراع |
| رقيب | 3 أشرطة على الذراع |
| رقيب أول | 3 أشرطة يعلوها التاج على الذراع |
| وكيل | شفرة نحاسية على الكتف |
| وكيل أول | شفرتان نحاسيتان على الكتف |
