# كيف تضيف ملخصاتك (ملفات .md)

الملخصات تظهر كبطاقة **"ملخص"** (بلون ذهبي) داخل القسم المناسب في صفحة العسكرية.
لإضافة ملخص جديد، اتبع خطوتين فقط:

## 1) ضع ملف الـ Markdown هنا

ارفع ملف `.md` داخل مجلد `military/summaries/`.
مثال: `military/summaries/hashemite-kingdom.md`

اكتب فيه ملخصك بصيغة Markdown العادية (عناوين `#`، قوائم `-`، جداول... إلخ).

## 2) سجّله في `summaries.json`

افتح ملف `military/summaries/summaries.json` وأضف عنصراً جديداً في المصفوفة:

```json
{
  "section": "المملكة الأردنية الهاشمية",
  "title": "ملخص: نشأة المملكة ومراحل التطور",
  "file": "summaries/hashemite-kingdom.md"
}
```

### شرح الحقول

| الحقل | المعنى |
|-------|--------|
| `section` | جزء **مميّز** من اسم القسم كما هو في قاعدة البيانات. إن طابقت العبارة أكثر من قسم يُختار الأدق (الأقصر اسماً). للتثبيت الدقيق اكتب **اسم القسم كاملاً** كما في قاعدة البيانات (مثل `القسم الرابع: المملكة الأردنية الهاشمية`). اترك القيمة فارغة `""` ليظهر في كل الأقسام. |
| `title`   | العنوان الظاهر على بطاقة الملخص (اكتب فيه الدروس التي يغطيها). |
| `file`    | مسار الملف بالنسبة لمجلد `military/` — أي يبدأ بـ `summaries/`. |

## ملاحظات

- يمكن أن يكون لقسم واحد **عدة ملخصات** (كل ملف يغطي مجموعة دروس) — فقط أضف عدة عناصر بنفس `section`.
- ترتيب البطاقات يتبع ترتيب العناصر في `summaries.json`.
- لا حاجة لتعديل ملف `index.html` إطلاقاً — فقط هذا المجلد.
- عبارات `section` المتاحة (أجزاء مميّزة من أسماء الأقسام):
  `المملكة الأردنية الهاشمية` · `مراحل تطور وبناء` · `نشأة وتطور القوات المسلحة` ·
  `أسلحة المناورة` · `أسلحة الإسناد` · `أسلحة الخدمات` · `وحدات حرس الحدود` ·
  `القوة البحرية والزوارق` · `سلاح الجو الملكي` · `المخابرات العامة`
